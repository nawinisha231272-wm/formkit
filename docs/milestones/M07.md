## Goal

Real-world forms usable end to end in all hosts, with no infrastructure of ours.

## Read first

AGENTS.md, `docs/progress.md`, `docs/spec/05-*.md`, `docs/spec/06-*.md`.

## Tasks

- [ ] Layouts: Panel, Columns (12-col widths), Fieldset; Container with object data scope.
- [ ] Controlled and uncontrolled modes in React and Angular; `<our-form>` property/attribute sync.
- [ ] Read-only mode; `submit()` flow with error summary; reset.
- [ ] `renderToString` SSR output and hydration-free re-mount on the client.
- [ ] Realistic 40-field fixture (customer onboarding) used in all examples.
- [ ] Benchmarks app: 100/500/1,000 fields; record the 500-field baseline; CI regression check.
- [ ] Package READMEs with runnable examples.

## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [ ] The 40-field fixture can be filled, validated and submitted in all three hosts (Playwright).
- [ ] Controlled mode round-trips data without lost keystrokes (test with rapid typing).
- [ ] 500-field baseline recorded; CI fails on > 20% regression.
- [ ] Gate: a sample app built from the packages runs with networking disabled.

- [ ] `pnpm verify` passes.
