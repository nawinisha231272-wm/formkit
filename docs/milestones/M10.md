# M10 — Complex components and async data

Phase: 4 — Complex components  
Branch: `m10-complex`  
Depends on: M09 merged  
Gate: no

## Goal

Nested arrays, multi-page forms, async data and files, all with stable row identity.

## Read first

AGENTS.md, `docs/progress.md`, `docs/spec/02-*.md`, `docs/spec/04-*.md`, `docs/spec/05-*.md`.

## Tasks

- [ ] Array scopes with `rowId`; session `addRow`/`removeRow`/`moveRow`; Repeater, DataGrid (virtualized, `cell` shells), EditGrid.
- [ ] Tabs; Wizard with per-page validation and navigation events.
- [ ] Date, Time, DateTime (ISO strings, locale display), Currency, Phone, Tags.
- [ ] Select/Autocomplete with data-source providers: debounce, abort, caching, `refreshOn` dependencies.
- [ ] File component using a host-provided storage provider (no built-in upload endpoint).
- [ ] Conformance and performance suites for grids and wizard.

## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [ ] Moving a row keeps that row's values, touched, errors and focus (test).
- [ ] 100-row DataGrid meets its benchmark budget.
- [ ] Async select cancels stale requests and never shows out-of-order results (test).
- [ ] All new components pass conformance in all hosts and themes.

- [ ] `pnpm verify` passes.

## Out of scope

- Renderer packs, Form.io import (after 1.0).
