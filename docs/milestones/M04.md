# M04 — Native bridges and host adapters

Phase: 0 — Architecture proof  
Branch: `m04-native-bridges`  
Depends on: M03 merged  
Gate: no

## Goal

The same form in vanilla, React and Angular, with existing app components registered in one line.

## Read first

AGENTS.md, `docs/progress.md`, `docs/spec/06-*.md`, `docs/spec/04-*.md`.

## Tasks

- [x] `registerNativeField` in sdk with convention-based prop mapping, overrides, and value inference rules (strings/numbers/booleans/arrays only; otherwise require `value` adapter).
- [x] `@ourform/element`: `<our-form>` custom element, `renderForm` helper, events and methods per 06.
- [x] `@ourform/react`: `<Form>`, `OurFormProvider`, `useForm`, `useField`, `registerReactField`, portal rendering of native fields.
- [x] `@ourform/angular`: standalone `<our-form>`, `provideOurForm`, `provideFormField`, `createComponent` mounting with the host injector, ControlValueAccessor support, zone-less compatible.
- [x] Sample `EmployeeLookup` control implemented natively in React and in Angular (search over a static list, value = employee id string); plus an object-valued variant using a value adapter.
- [x] Example apps `apps/vanilla-example`, `apps/react-example`, `apps/angular-example` rendering the same fixture.
- [x] Cross-host conformance test: identical submitted data and error sets for the fixture in all three hosts.

## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [x] One fixture renders in vanilla, React and Angular examples; submitted data identical (test).
- [x] Native EmployeeLookup receives value, change, blur, disabled and readOnly in React and Angular (tests).
- [x] Conventional control registration is a single statement (shown in examples).
- [x] Object-valued control without a value adapter fails with a clear error; with one it works.
- [x] React context from the host app is visible inside a native React field (test).
- [x] Angular DI from the host app works inside a native Angular field (test).

- [x] `pnpm verify` passes.
