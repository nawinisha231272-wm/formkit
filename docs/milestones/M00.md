## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [x] Fresh clone: `pnpm install && pnpm verify` passes with no global tools.
- [x] The three starter-kit behaviours (registry/defaults/validation/subscriptions, duplicate type rejected, duplicate key rejected) are covered by Vitest tests that pass.
- [x] `@ourform/core` builds with no `DOM` in `lib` and contains no DOM type references.
- [x] A deliberate relative import between packages fails `pnpm lint` (test or documented check).
- [x] Playground runs with `pnpm dev` and the Playwright smoke test passes.
- [x] No `dist/` or build output is committed.

- [x] `pnpm verify` passes.
