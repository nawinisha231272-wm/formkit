# M09 — Builder with nested drag and drop

Phase: 3 — Builder  
Branch: `m09-builder`  
Depends on: M08 merged  
Gate: no

## Goal

A usable visual builder where containers declare their drop slots once and custom components work
with zero builder code, including nested mouse and keyboard authoring.

## Read first

AGENTS.md, `docs/progress.md`, `docs/spec/04-sdk.md`, `docs/spec/07-builder.md`, ADR-0014.

## Tasks

- [ ] Add the headless slot contract to ComponentModel: `slots: [{ name, label, accepts, max? }]`; share slot resolution/validation between compile, builder and renderer. Allow instance-derived slots for configurable Tabs, without container-specific builder logic.
- [ ] Keep ordered `components` and add optional child `slot` names. Preserve existing default-slot layouts and JSON without materializing defaults.
- [ ] Enforce drop rules in builder-core: reject self/descendant drops, unknown slots, incompatible kinds/types, capacity violations and root-only placement violations. Re-check key uniqueness across data scopes; report stale path references when paths change.
- [ ] Full command set: Add, Remove, Move into any slot at any depth, UpdateProperty, Duplicate subtree, ChangeKey, WrapInLayout, Unwrap. Emit replayable RFC 6902 JSON Patch and retain bounded undo/redo history; diagnostics `stale-path`, `dangling-ref`.
- [ ] Canvas in renderer `design` mode, with drop indicators inside Panel, Fieldset, Container, Columns and Tabs, between children and in empty slots. Visible reasons for refused operations.
- [ ] Move Tabs from M10 into M09: configurable tab slots/captions, accessible keyboard navigation, persistent child controls/state across tab and theme changes, design mode exposing every slot.
- [ ] Keyboard cut/paste into the selected slot, Alt+arrows to reorder/reparent, selection/edit/delete navigation, and an accessible outline tree.
- [ ] Generated property panel incl. expression editor for `expr` properties; JSON view with diagnostics; preview.
- [ ] `@ourform/builder` UI, `<our-form-builder>`, React and Angular wrappers; `of-schema-change` events with JSON Patch.
- [ ] Builder chrome styles independent of form theme.

## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [ ] Registering Rating or a native field makes it appear and be editable with zero builder code (test).
- [ ] Build `Tabs > Panel > Columns > field` (four levels) by mouse and independently by keyboard alone.
- [ ] Illegal drops are refused atomically with a visible reason; tests cover cycles, accepts, max, unknown slots and root-only placement.
- [ ] An SDK component declaring slots becomes a drop target with zero builder code, including a field-only slot.
- [ ] Moving a field into Container changes its compiled data path, reports stale path references, and rejects key conflicts without changing state/history.
- [ ] Undo/redo restores byte-identical JSON for 50 random command sequences including nested moves, duplication, wrapping and unwrapping; independent patch replay matches each committed state. Bounded-history behavior is tested separately.
- [ ] Keyboard-only form building (add, configure, move, delete) passes Playwright.
- [ ] Tabs passes conformance and visual comparisons in Base, Bootstrap 4, Bootstrap 5 and Tailwind, across the supported hosts. Tab/theme switching retains controls, values, focus where applicable, and session state.
- [ ] DOM builder, custom element, React and Angular wrappers emit schema changes with replayable JSON Patch; JSON import and expression editors report invalid input without corrupting the draft.
- [ ] axe: zero serious/critical issues in the builder.

- [ ] `pnpm verify` passes.

## Out of scope

- Collaboration, templates library, array scopes/grid row execution/Wizard (M10a), advanced inputs (M10b).
