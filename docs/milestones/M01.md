# M01 — Schema and core engine

Phase: 0 — Architecture proof  
Branch: `m01-core-engine`  
Depends on: M00 merged  
Gate: no

## Goal

The headless runtime with real paths, compile step, expressions, dependency graph and per-field state.

## Read first

AGENTS.md, `docs/progress.md`, `docs/spec/01-*.md`, `docs/spec/02-*.md`, `docs/spec/03-*.md`.

## Tasks

- [x] `@ourform/schema`: full `FormDefinition`/`ComponentNode`/`ValidationRules` types; JSON Schema 2020-12 meta-schema; `validateDefinition` with stable diagnostic codes; `migrate` harness.
- [x] `@ourform/core`: `createEngine`, per-engine `Registry`, `compile()` returning `CompileResult` (never throws on user input).
- [x] Paths: `Path` type, `parsePath`, `formatPath`, compiled path index; data scopes for `dataScope: 'object'` (a basic `container` model for tests).
- [x] Store: copy-on-write updates along the changed path; `getData` returns structurally shared snapshots.
- [x] Expressions: parser/validator for the compact array format, evaluator per 03-expressions (depth/node limits, safe property access), `call` to registered functions, dependency recording.
- [x] Dependency graph with topological processing and cycle detection (`cycle` diagnostic listing all members).
- [x] Session: `FieldState`, `setValue` pipeline (normalize → calculate → visibility/disabled → clear-on-hide → validate per `validateOn`), `touch`, `validate`, `submit`, `reset`, `subscribe` with one `StatePatch` per change.
- [x] Built-in rules: required, minLength, maxLength, min, max, pattern; message keys `of.validation.*`.
- [x] Processor-run instrumentation for tests.
- [x] 20 fixtures in `fixtures/forms` covering flat, nested container, conditionals, calculations, clear-on-hide, cycles (invalid), unknown types (invalid).
- [x] Update the renderer and playground minimally so they still work with the new session API (no new UI features).

## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [x] All core tests run in Node with no DOM environment.
- [x] Changing one field reprocesses only it and its transitive dependents (instrumentation assertion on a 200-field fixture).
- [x] A calculation cycle produces a compile error naming every component in the cycle.
- [x] Hidden fields with `clearOnHide` are emptied and not validated; visible again → default restored.
- [x] Lint rule (or test) proves no `eval`, `new Function` or `with` exist in the repo.
- [x] Prototype-pollution attempts (`__proto__` keys, paths) are rejected with diagnostics (tests).
- [x] Core line coverage ≥ 90%.

- [x] `pnpm verify` passes.

## Out of scope

- Arrays/repeaters (M10), async validators (M6), DOM work beyond keeping the playground alive.
