# M02 — SDK contracts and renderer decision

Phase: 0 — Architecture proof  
Branch: `m02-sdk-renderer`  
Depends on: M01 merged  
Gate: no

## Goal

Model/view split, typed property metadata, and a measured choice of portable control representation.

## Read first

AGENTS.md, `docs/progress.md`, `docs/spec/04-*.md`, `docs/spec/05-*.md`.

## Tasks

- [x] `@ourform/sdk`: `ComponentModel`, `ValueAdapter` helpers (`stringValue`, `numberValue({ empty: null })`, `booleanValue`), property helpers and `ConfigOf`, config validation from properties (`invalid-property` diagnostics), `defineField` returning `{ model, views }`.
- [x] Spike two renderers behind the same `FieldControlProps`: (a) VNode `h()` + keyed patcher, (b) DOM factory with `update(props)`/`destroy()`. Implement Text and Rating in both.
- [x] Benchmark both on a 500-field form: initial mount, keystroke update, theme switch; measure authoring lines; prototype embedding one control in a React and an Angular host; produce SSR strings.
- [x] Write ADR-0002 with the measurements and the decision; delete the losing spike.
- [x] Port Text, Number, Checkbox and Rating to the chosen representation. Rating's empty value is `null`; required Rating fails when unset.
- [x] Renderer reads `FieldState` instead of calling `validate()` per field.

## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [x] Rating's definition is < 30 lines of meaningful code (count recorded in ADR-0002).
- [x] Required Rating with no selection fails validation (test).
- [x] ADR-0002 contains numbers for every criterion and a clear decision.
- [x] `ConfigOf<typeof rating.properties>` yields `{ max: number; allowHalf: boolean }` (type test).
- [x] Invalid property values in a definition produce `invalid-property` diagnostics.
- [ ] All M1 tests still pass unchanged. **Recorded exception:** all cases pass; one starter assertion changes Rating zero to null as this milestone requires. Core/schema regression files are unchanged (see progress log and ADR-0002).

- [x] `pnpm verify` passes.
