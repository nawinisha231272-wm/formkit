# M10b — Advanced inputs and async data

Phase: 4 — Complex components

Branch: `m10b-advanced-inputs`

Depends on: M09d and M10a merged after owner review

Gate: no

## Goal

Advanced scalar/multi-value inputs, async choices and host-owned files with explicit nullable adapters.

## Read first

AGENTS.md, `docs/progress.md`, `docs/spec/02-runtime.md`, `docs/spec/04-sdk.md`,
`docs/spec/05-rendering-themes.md`, `docs/spec/06-adapters.md`, accepted ADR-0019.

## Tasks

- [ ] Date, Time and DateTime (ISO model values, locale display).
- [ ] Async Select and Autocomplete using host data-source providers: debounce, abort, caching and `refreshOn` dependencies.
- [ ] File through a host-provided storage provider; no built-in upload endpoint.
- [ ] Currency, Phone and Tags.
- [ ] Build Currency from Number and Phone from Text with `extendField` when canonical adapters
      remain compatible; use kits for currency defaults and regional phone variants. Extend Select
      for async Select only if its adapter and inherited membership validation remain valid;
      otherwise use a new model. Extend compatible bases for Autocomplete/Date/Time/DateTime only after
      proving value/required/serialization compatibility. File and Tags need their own adapters/models
      before variants are derived. Explicit adapter replacement requires M09d conformance checks.
- [ ] Document every adapter's nullable/empty/normalize/isEmpty/equals/serialize/jsonSchema contract and required semantics, including Node/browser parity.
- [ ] Generated property editors, author examples and conformance/visual coverage for every input.

## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [ ] Async choices cancel stale requests and never show out-of-order results; teardown releases timers, subscriptions and pending work.
- [ ] Date/time/currency/phone/tag/file canonical values, empty handling, required validation and submission behavior match in browser and Node.
- [ ] File I/O occurs only through the configured host provider.
- [ ] Every new component passes conformance in all hosts and visual checks in Base, Bootstrap 4, Bootstrap 5, Tailwind and Material.
- [ ] `pnpm verify` passes.

## Out of scope

- Renderer packs, Form.io import, additional structures beyond M10a.
