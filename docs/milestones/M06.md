## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [ ] Browser and Node produce identical validation results for every fixture (test).
- [ ] Generated JSON Schema accepts every good and rejects every bad fixture submission in Ajv.
- [ ] Every Tier 1 field passes the component conformance suite in all three hosts.
- [ ] Content component strips scripts, event handlers and `javascript:` URLs (tests).
- [ ] Validation line coverage ≥ 90%.

- [ ] `pnpm verify` passes.
