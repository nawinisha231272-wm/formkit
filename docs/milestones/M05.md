- [ ] `@ourform/builder-core`: `createBuilder`, commands AddComponent, UpdateProperty, RemoveComponent with `invert`, undo/redo, JSON Patch output, palette from registry, property panel model (base groups + model properties).

## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [ ] Same JSON form renders in Vanilla JS, Angular and React.
- [ ] Custom Rating control is created without class inheritance.
- [ ] Existing React component registers and receives value/blur/disabled state.
- [ ] Existing Angular component registers with equivalent behaviour.
- [ ] Custom component appears automatically in the builder palette.
- [ ] Component properties automatically generate the builder property editor.
- [ ] Base, Bootstrap 5 and Tailwind themes work without rewriting Rating.
- [ ] Switching themes preserves form state.
- [ ] Client-side validation works with no backend.
- [ ] The project builds and runs with no network access to any licensing endpoint (offline build test).

- [ ] `pnpm verify` passes.
