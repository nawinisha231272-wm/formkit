# M10a — Data structures

Phase: 4 — Complex components

Branch: `m10a-data-structures`

Depends on: M09 merged

Gate: no

## Goal

Nested arrays, editable grids and multi-page forms with stable row identity and declarative drop slots.
Tabs already ships in M09.

## Read first

AGENTS.md, `docs/progress.md`, `docs/spec/02-runtime.md`, `docs/spec/04-sdk.md`,
`docs/spec/05-rendering-themes.md`, `docs/spec/07-builder.md`, ADR-0014.

## Tasks

- [ ] Array scopes with stable `rowId`; session `addRow`/`removeRow`/`moveRow`.
- [ ] Repeater, DataGrid (virtualized, `cell` shells), EditGrid and Wizard, each declaring slots through the M09 contract.
- [ ] Grid column slots accept fields only; Wizard pages are restricted to the top level. Apply the shared nested-drop rules without container-specific builder changes.
- [ ] Wizard per-page validation, navigation events and preserved page state.
- [ ] Shared host/theme conformance and grid/Wizard performance-count/timing fixtures.

## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [ ] Moving a row preserves that row's values, touched/errors/pending state and focus by `rowId`.
- [ ] 100-row DataGrid meets its deterministic work and size budgets; isolated timings are reported under ADR-0010.
- [ ] Every structure's declared slots work in the existing builder without new drop-target code; illegal grid/page drops show a reason.
- [ ] Wizard validation/navigation and undo/redo of nested structures pass browser/Node tests.
- [ ] Every new component passes conformance in all hosts and visual checks in Base, Bootstrap 4, Bootstrap 5 and Tailwind.
- [ ] `pnpm verify` passes.

## Out of scope

- Advanced inputs (M10b), renderer packs, Form.io import.
