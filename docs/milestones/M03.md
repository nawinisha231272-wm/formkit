# M03 — FieldShell, accessibility and themes

Phase: 0 — Architecture proof  
Branch: `m03-shell-themes`  
Depends on: M02 merged  
Gate: no

## Goal

Everything around the control: shells, ARIA, focus, and three real themes with state-preserving switching.

## Read first

AGENTS.md, `docs/progress.md`, `docs/spec/05-*.md`, `docs/spec/04-*.md`.

## Tasks

- [x] Implement shell variants `field`, `group`, `inline`, `cell`, `none` with the anatomy parts from 05.
- [x] ARIA wiring: ids, `for`, `aria-describedby`, `aria-invalid`, `aria-required`; one `aria-live` region; error summary on failed submit with focus links; `focusRef` and `mount().focus()`.
- [x] Theme runtime: token style block, class maps, resolution order, scoping attribute, dark and high-contrast modes.
- [x] `@ourform/theme-base`, `@ourform/theme-bootstrap5`, `@ourform/theme-tailwind` (compiled CSS shipped in the package).
- [x] `setTheme` swaps classes/tokens on existing elements without rebuilding DOM.
- [x] Theme conformance suite in `@ourform/testing` (states, validation, disabled, read-only, focus, RTL, dark, high-contrast) with visual snapshots.

## Acceptance criteria

Each needs a test or reproducible check named in `docs/progress.md`.

- [x] axe: zero serious/critical violations in the playground for all three themes, light and dark.
- [x] Typing in a field, switching theme, and continuing to type keeps focus, caret and value (Playwright).
- [x] Rating uses the `group` shell; screen-reader name comes from the legend (axe + DOM assertion).
- [x] Rating renders correctly in all three themes with no changes to its definition.
- [x] Keyboard-only completion and submission of the feedback fixture passes.

- [x] `pnpm verify` passes.

## Out of scope

- Native framework bridges (M4).
