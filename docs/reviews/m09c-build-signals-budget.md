and expanded object refs) separately from data-cycle edges. A former shallow freeze left child graph
arrays mutable; a new regression catches that, and the program now deep-freezes its graph. Four new
core regressions first fail, then pass; all **182 core tests** pass and typecheck passes.

property links. Inherited state includes descendant fields; caption-only layout changes do not count
children, and caption-only field changes do not count unchanged value dependants. Root visibility
chips/summary fold position-zero legacy visibility, later rules, explicit otherwise and ancestor
visibility. Legacy behavior stays unchanged when no relevant root visibility exists. **Nine builder
signal tests pass**. No raw expression parsing or rule-list scan is added to ordinary form edits.
