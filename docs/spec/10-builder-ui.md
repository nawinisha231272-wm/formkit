# 10 — Builder UI replacement (M09b)

Status: planned; replaces the current M09 builder harness. M09a does not implement this UI.

The owner requires Pointer Events dragging, drop indicators shown only during a drag, selection by
click, only the active tab rendered visibly on the authoring canvas, and a tabbed edit dialog.
Keep engine-owned per-column slots, atomic drop rules, keyboard alternatives, replayable patches and
bounded undo/redo. Detailed interaction design and acceptance belong to M09b, before implementation.
