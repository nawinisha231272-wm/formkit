# OurForm author guides

- [Component author guide](component-author-guide.md): control-only fields, presets, composites,
  native mappings, plugins and the test kit.
- [Theme author guide](theme-author-guide.md): tokens/classes, modes, conformance and visual checks.

Run the repository playground and open `/sdk-extensions.html` for the executable M08 examples.
These are self-hosted SDK guides. No account, hosted API or network access is needed at runtime.

Open `/authoring.html` in the playground for the compiled Quantity example, simplified Slider and
metadata-driven mini builder. Rehearsal records in `docs/rehearsals/` are AI-assisted evidence only;
the independent human trial is still required for the M08 gate.
