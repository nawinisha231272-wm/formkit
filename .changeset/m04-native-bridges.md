Add per-host native field descriptors, opaque renderer slots, Web Component/vanilla, React portal and
Angular DI/CVA adapters. Preserve controlled data, native editing and host context, with cross-host
conformance examples for React 19 and Angular 22/21. Angular is built by ng-packagr; tslib supplies its
compiler helpers. Frameworks remain peers, and no global registry or customer-data network service is added.
